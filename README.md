# 箱庭 Hakoniwa · Izu

A diorama builder inspired by the Izu peninsula. Shape a little island, carve waterfalls into cedar
gorges, raise basalt sea cliffs, lay railways and build tea rooms, temples and stations, then drag the
timeline and watch a century happen to it.

## Download

Get the newest build from **[Releases](../../releases/latest)**:

- **Windows:** `Hakoniwa-Izu-Windows.exe`. Double-click to play. If SmartScreen appears, click
  *More info → Run anyway*.
- **Mac:** `Hakoniwa-Izu-Mac.zip`. Unzip, move the app to Applications, then right-click it and choose
  *Open*. If macOS says it is damaged, run
  `xattr -dr com.apple.quarantine "/Applications/Hakoniwa Izu.app"` in Terminal once.

Copies update themselves: when a new build is out, the game downloads it in the background and uses it
the next time you open it.
